=====================================================
  걸어 다니는 방탈출 - 만드는 법
=====================================================

구조는 세 가지만 기억하면 됩니다.

  1) 방 하나 = 맵 하나        (그림은 맵의 '원경'으로 깔기)
  2) 조사할 물건 = 이벤트      (이벤트 '이름'만 데이터 파일의 id와 똑같이)
  3) 지나가면 안 되는 곳 = 리전 1번 칠하기

대사, 자물쇠, 퀴즈, 아이템 같은 내용은 전부 data/EscapeData.json 한 파일에 들어 있습니다.


-----------------------------------------------------
조작법 (학생용)
-----------------------------------------------------
  방향키 / 마우스 클릭 : 걷기
  Enter, Space, 클릭  : 앞에 있는 물건 조사 (가까이 가면 이름표가 뜸)
  ESC, X, 오른쪽 클릭  : 가방 (모은 물건 보기, 힌트 보기)
  H                   : 힌트
  문은 걸어 들어가면 열립니다.


=====================================================
A. MV 편집기에서 하는 일
=====================================================

■ 맵 만들기
  맵 목록에서 오른쪽 클릭 → 새로 만들기(또는 편집)
  - 크기: 폭 29, 높이 13  (가운데 17칸 = 실제 방, 양옆 6칸씩 = 바깥 장식 마당)
    ※ 화면 비율 자동 맞춤(v2.6): 4:3 기기는 가운데 17칸만, 16:9는 양옆 3칸씩,
       휴대폰 가로는 거의 29칸 전부가 보입니다. 지도는 늘 가운데에 고정됩니다.
    ※ 단서·자물쇠·문 같은 꼭 필요한 것은 반드시 가운데 17칸(x 6~22) 안에 두세요.
       양옆 6칸은 리전 1번(벽)으로 모두 칠해 두면 주인공이 들어가지 않습니다.
  - 원경: img/parallaxes 폴더의 그림을 고르고 "에디터에 표시"에 체크
    ※ 그림 이름을 느낌표로 시작하면(!bg_palace) 그림이 바닥에 딱 붙어 움직이지 않습니다.
  - 타일은 칠하지 않아도 됩니다.

■ 원경 그림 규칙
  - 크기 1392 x 624 (= 29칸 x 13칸, 한 칸 48픽셀). 가운데 816픽셀이 실제 방
    (옛날 816 x 624 그림도 폭 17 맵에서는 그대로 쓸 수 있어요. 그때는 양옆이 검게 보일 수 있습니다.)
  - 위에서 내려다본 방 그림
  - 맨 위 한 줄(48픽셀)은 시간·버튼 표시줄이 덮으니 벽/지붕을 그려 두세요.

■ 벽 칠하기 (리전)
  1) 맵 모드(F5)에서 왼쪽 타일 팔레트 아래쪽 탭 중 [R] 탭을 누릅니다.
  2) 팔레트에서 1번을 고르고, 벽과 가구 칸을 칠합니다. (지우려면 0번)
  → 리전 1번 칸은 주인공이 지나갈 수 없습니다.

■ 등장인물(NPC) 놓기
  이벤트를 만들고 이름을 데이터 파일 id로 적은 뒤, 이벤트 그림에서 캐릭터를 고르면 됩니다.
  말을 걸면 주인공 쪽으로 돌아봅니다.

■ 조사할 물건 놓기 (이벤트)
  1) 이벤트 모드(F6)로 바꾸고, 물건이 있는 칸을 더블클릭합니다.
  2) 이름 칸에 데이터 파일의 id를 적습니다.  예: box
  3) 우선순위·트리거·실행 내용은 그대로 두고 확인. (플러그인이 알아서 처리합니다)
  - 큰 물건(보관대, 가마)은 같은 이름의 이벤트를 여러 칸에 놓으면 됩니다.
    가장 빠른 방법: 이벤트 하나 만들고 Ctrl+C, 옆 칸 클릭 후 Ctrl+V
  - 문처럼 "걸어 들어가면" 반응해야 하는 곳은 트리거를 [플레이어로부터 접촉]으로 바꾸세요.
    (그냥 두어도 문 앞에서 Enter를 누르면 열립니다)
  - 데이터 파일에 없는 이름의 이벤트는 보통 MV 이벤트처럼 동작합니다.

■ 맵 번호 확인
  맵 목록에서 맵을 고르면 편집기 아래쪽 상태줄에 맵 번호(예: 001)가 보입니다.
  이 번호를 데이터 파일의 "map"에 적습니다.

■ 좌표 확인
  맵 위에 마우스를 올리면 편집기 아래쪽 상태줄에 칸 좌표(예: 14,11)가 보입니다.
  (넓은 맵에서는 실제 방의 왼쪽 벽이 x=6, 오른쪽 벽이 x=22입니다)
  "start"(도착 위치)와 "go"의 x, y에 씁니다.

■ 제작 도우미
  플러그인 관리 → EscapeRoom → "제작 도우미 보기"를 [보기]로 바꾸고 테스트하면:
  - 빨간 칸 = 벽(리전 1번)
  - 노란 칸 = 데이터 파일과 연결된 조사 이벤트 (이름 표시)
  - 파란 칸 = 연결되지 않은 일반 이벤트 (이름 오타가 있으면 여기 파랗게 보임)
  - 화면 아래: 주인공 좌표, 그리고 "이벤트가 없는 조사 지점" 목록
  다 만들면 꼭 [숨기기]로 돌려 놓으세요.


■ 효과음 바꾸기
  플러그인 관리 → EscapeRoom을 더블클릭하면 '효과음: 문 열림 / 퍼즐 해결 / 아이템 획득 /
  시간의 문 / 시대 이동' 칸이 있습니다. audio/se 폴더에 있는 파일 이름(확장자 빼고)을 적으세요.
  칸을 비우면 그 효과음은 나지 않습니다.


=====================================================
B. 데이터 파일(EscapeData.json) 쓰는 법
=====================================================
메모장이나 VS Code로 열어 고칩니다. (VS Code는 오류를 빨갛게 표시해 줘서 편해요)
고친 뒤 게임이 안 켜지면 화면에 오류 위치가 나옵니다.
대부분 쉼표(,) 빠짐, 따옴표(") 짝 안 맞음, 괄호 짝 안 맞음입니다.

-----------------------------------------------------
1. 기본 설정
-----------------------------------------------------
  "title"        게임 제목
  "timeLimit"    제한 시간(초). 1200 = 20분, 0 = 제한 없음
  "hints"        힌트 횟수. 0이면 힌트 버튼이 사라짐
  "wrongPenalty" 오답일 때 줄어드는 시간(초). 0 = 감점 없음
  "startRoom"    처음 시작하는 방의 id

  ▶ 타이틀 · 음악 · 영상 (맨 위에 적는 설정)
  "gameTitle":  "시간의 문: 고려를 건너다"   게임 이름 (창 제목에도 쓰임)
  "titleImage": "TimeGate_Title"           img/titles1 폴더의 타이틀 그림 (1392x624 권장, 가운데 816이 기본 화면)
  "titleText":  false                      그림에 이름이 이미 들어 있으면 false (글자를 따로 안 씀)
  "titleBgm":   "Goryeo_Title"             타이틀 화면 음악 (audio/bgm)
  "bgm":        "Goryeo_Explore"           방에서 기본으로 나오는 음악
  "endingBgm":  "Goryeo_Finale"            탈출 성공 후 엔딩 음악
  방마다 다른 음악을 쓰려면 방 설정에 "bgm": "Goryeo_Tension" 처럼 적습니다.
  * 음악은 .ogg(컴퓨터용)와 .m4a(휴대폰·웹용) 두 가지를 같은 이름으로 넣어 두세요.
  * 파일이 없으면 그 음악·그림만 건너뛰고 게임은 정상 진행됩니다.


  ▶ 후기 링크 (엔딩이 끝난 뒤)
  "review": { "url": "https://forms.gle/9PfM9UU7hb5RcCwd6",
              "picture": "cu_review",
              "text": "끝까지 함께해 줘서 고마워요! Enter나 클릭을 누르면 후기 페이지가 열려요." }
  * 엔딩 정리가 끝나면 안내 화면이 나오고, Enter·클릭을 누르는 순간 링크가 열립니다.
    (컴퓨터에 설치한 게임은 기본 브라우저로, 웹으로 올린 게임은 새 탭으로 열려요)
  * 주소를 바꾸면 cu_review.png 그림 속 QR도 새로 만들어야 합니다. 원하시면 만들어 드릴게요.
  * 후기를 받지 않으려면 "review" 부분을 통째로 지우세요.


-----------------------------------------------------
2. 방 (rooms)
-----------------------------------------------------
  { "id": "palace",                 ← 방 이름표(영어/숫자)
    "name": "918년 · 개경 왕궁",      ← 화면 왼쪽 위에 보이는 이름
    "map": 1,                        ← MV 맵 번호
    "start": [14, 11, "up"],         ← 이 방에 들어왔을 때 서는 칸 (x, y, 바라보는 방향)
    "enter": [ ... ],                ← (선택) 처음 들어왔을 때 한 번 나오는 글
    "hotspots": [ ... ] }            ← 조사 지점들

  방향: "up", "down", "left", "right"

-----------------------------------------------------
3. 조사 지점 (hotspots)
-----------------------------------------------------
  { "id": "box", "label": "보물함", "steps": [ ... ] }

  id    = MV 이벤트 이름과 똑같이
  label = 그 앞에 섰을 때 머리 위에 뜨는 이름표

  ▶ 상황에 따라 다른 반응 (cases) - 위에서부터 조건이 맞는 첫 번째만 실행
    "cases": [
      { "if": { "flag": "p1" },   "steps": [ ...이미 풀었을 때... ] },
      { "if": { "item": "key" },  "steps": [ ...열쇠가 있을 때... ] },
      {                           "steps": [ ...그 밖의 경우... ] }
    ]

  ▶ 조건이 맞을 때만 조사 가능 (when)
    "when": { "flag": "p2" }

  ▶ 조건 종류
    "flag": "p1"            p1을 풀었다       "noFlag": "p1"    아직 안 풀었다
    "item": "knife"         조각칼이 있다      "noItem": "knife" 조각칼이 없다
    "items": ["a","b","c"]  셋 다 있다

-----------------------------------------------------
4. 동작 (steps) - 위에서부터 차례로 실행
-----------------------------------------------------
  { "text": "보물함이다." }                          글
  { "speaker": "도공", "text": "어서 오너라." }        이름표와 함께
  { "picture": "cu_yeonpyo", "text": "연표다." }       그림을 크게 띄우고 글 (img/pictures)
  { "give": "knife" }                               아이템 주기
  { "take": ["baekto", "jato"] }                    아이템 가져가기
  { "solve": "p1" }                                 퍼즐 해결 표시(효과음 포함)
  { "flag": "door_open" }                           표시만 하기
  { "go": "workshop" }                              다른 방으로 (그 방의 start 위치로)
  { "go": "palace", "x": 13, "y": 2, "dir": "down" } 다른 방의 원하는 칸으로
  { "escape": true }                                탈출 성공 → 엔딩
  { "penalty": 30 }                                 시간 30초 줄이기
  { "se": "Door1" }                                 효과음 (audio/se에 있는 이름. 없으면 조용히 넘어감)

  한 칸에 여러 개를 함께 써도 됩니다.
  예) { "give": "celadon", "solve": "p3", "text": "상감청자를 얻었다!" }

  ▶ 영상 · 음악 바꾸기
  { "movie": "intro_goryeo" }   movies 폴더의 영상(.webm 컴퓨터용 + .mp4 휴대폰용)을 재생
                                재생 중 Enter·클릭으로 건너뛸 수 있습니다.
  { "bgm": "Goryeo_Tension" }   음악 바꾸기,  { "bgm": "" } 음악 끄기

  ▶ 효과 (effect) - 다른 동작과 한 칸에 함께 써도 됩니다
  { "effect": "door", "target": "exit" }      target 이벤트 자리에서 빛·불꽃이 터지고 문 열리는 소리
  { "effect": "flash", "color": [255,255,255,200], "duration": 30 }   화면 번쩍 (빨강,초록,파랑,세기)
  { "effect": "shake", "power": 5, "duration": 24 }                  화면 흔들림
  { "effect": "sparkle", "target": "box" }    반짝이 (target을 빼면 주인공 자리)
  { "effect": "card", "text": "1170 · 무신정변" }                    큰 제목 카드
  { "effect": "gate", "target": "gate", "items": ["celadon", "tripitaka", "metaltype"] }
                                              시간의 문 연출 (보물이 날아가고 하얗게 사라짐)
  * 퍼즐 해결(solve), 아이템 획득(give), 오답, 처음 들어간 방의 제목 카드는 자동으로 나옵니다.
  * "go"에 "fade": "white"를 붙이면 하얗게 번쩍이며 이동합니다 (시대 이동 느낌).

  ▶ 열린 문 표시 (조사 지점에 붙이는 설정)
  { "id": "exit", "label": "공방 문", "open": { "flag": "p4" }, ... }
  조건이 맞으면 그 자리가 계속 환하게 빛납니다 (다시 돌아와도 열린 채로 보임).
  "openStyle": "glow" 를 함께 쓰면 문 대신 큰 빛무리(시간의 문처럼)가 됩니다.

  ▶ 숫자 자물쇠
  { "lock": { "digits": 3, "answer": "918", "question": "세 자리 자물쇠다." },
    "success": [ ... ],  "fail": [ ... ] }       ← fail은 빼도 됨
  * answer는 꼭 따옴표로. 키보드 숫자로도 입력 가능, ESC로 그만두기.

  ▶ 다이얼 자물쇠 (글자·방향·색깔 등, 칸마다 돌려 맞추는 자물쇠)
  같은 보기를 여러 칸에 쓸 때:
  { "dial": { "symbols": ["↑", "→", "↓", "←"], "count": 4,
              "answer": ["↑", "←", "←", "↑"], "question": "화살표 자물쇠다." },
    "success": [ ... ], "fail": [ ... ] }
  칸마다 보기가 다를 때 (labels는 칸 위에 붙는 이름표, 빼도 됨):
  { "dial": { "labels": ["학", "구름"], "slots": [["백토","자토"], ["백토","자토"]],
              "answer": ["백토", "자토"], "question": "무늬마다 흙을 고르자." } , ... }
  * 방향키 ←→로 칸 이동, ↑↓로 돌리기, 마우스로 ▲▼ 클릭도 됨.
  * 단서 그림("picture")을 띄운 바로 다음에 다이얼을 쓰면, 그림을 보면서 풀 수 있게
    다이얼이 화면 아래로 내려갑니다.

  ▶ 선택지 퀴즈
  { "choice": ["보기1", "보기2", "보기3", "보기4"],
    "answer": 1,                                ← 정답 번호(1부터)
    "speaker": "도공", "question": "상감 기법이란?",
    "success": [ ... ], "fail": [ ... ] }
  * answer를 빼면 정답·오답 없이 고른 번호에 따라 "on1", "on2" ... 를 실행합니다.
    예) "on1": [ ...1번을 골랐을 때... ], "on2": [ ...2번을 골랐을 때... ]

  ▶ 주인공 고르기 (보통 intro에 한 번)
  { "selectCharacter": true, "question": "주인공을 골라 주세요." }
  고를 수 있는 목록은 맨 위의 "characters"에 적습니다.
  "characters": [ { "label": "남학생", "image": "$student_m" },
                  { "label": "여학생", "image": "$student_f" } ]
  image = img/characters 폴더의 캐릭터 그림 이름. 첫 번째가 기본값입니다.

-----------------------------------------------------
5. 아이템 (items)
-----------------------------------------------------
  "knife": { "name": "조각칼", "image": "item_knife", "desc": "무늬를 파내는 칼." }
  image = img/pictures의 그림 (정사각형 96x96 정도)
  가방에서 고르면 그림이 크게 뜨고 desc가 나옵니다.

-----------------------------------------------------
6. 퍼즐 목록과 힌트 (puzzles)
-----------------------------------------------------
  { "id": "p1", "name": "보물함", "hints": ["1단계 힌트", "2단계 힌트(거의 정답)"] }
  힌트는 '아직 안 푼 첫 번째 퍼즐' 것이 나오니, 푸는 순서대로 적으세요.
  id는 "solve"에 쓴 이름과 같아야 합니다.

-----------------------------------------------------
7. 도입과 엔딩
-----------------------------------------------------
  "intro":  시작할 때 나오는 steps
  "ending": { "success": [...], "fail": [...], "summary": [...] }
  성공하면 걸린 시간과 힌트 수가 자동으로 나오고, 끝나면 타이틀로 돌아갑니다.


=====================================================
C. 새 주제 만들기 순서
=====================================================
  1) 프로젝트 폴더를 통째로 복사 (MV를 닫은 상태에서)
  2) img/parallaxes의 방 그림을 새 그림으로 교체 (같은 이름이면 맵 설정 그대로)

E. 어드벤처 기능 (v3.0) - 독도 편에서 처음 사용
=====================================================
■ 화면이 주인공을 따라가는 넓은 지도
  방에 "camera": "follow" 를 적습니다. (적지 않으면 예전처럼 지도가 가운데 고정)
  넓은 지도는 그림 한 장이 가로·세로 4096픽셀을 넘지 않게 (예: 52 x 80칸 = 2496 x 3840)

■ 배 타기
  리전 2번 = 바다 (배로만 지나감), 리전 3번 = 부두 (걸어서·배로 모두), 리전 1번 = 벽
  단계 { "boat": true } 배 타기 / { "boat": false } 내리기
  "go"와 함께 쓰면 도착하는 순간 바뀝니다:
     { "go": "world", "x": 33, "y": 60, "boat": true }
  조건에도 쓸 수 있어요:  "cases": [ { "if": { "boat": true }, "steps": [...] }, ... ]
  배 그림: 데이터 맨 위 "boatSprite": "$boat"  (배를 타면 조금 빨라짐)
  섬에 배를 대는 곳: 섬 칸에 이벤트를 놓고 트리거를 [플레이어로부터 접촉]으로

■ 추격 (액션)
  { "chase": { "targets": ["jboat1","jboat2","jboat3"],    ← 쫓을 이벤트 이름
               "time": 90, "speed": 5,                      ← 제한 시간(초), 달아나는 속도
               "smart": 0.9, "sight": 10, "pause": 0.2,     ← 영리함, 알아채는 거리, 쉬는 확률
               "label": "일본 어선 따라잡기", "caughtText": "따라잡았다!",
               "success": [...], "fail": [...] } }
  주인공이 배일 때 쫓기는 이벤트도 바다로만 다닙니다. 실패하면 자동으로 다시 시작.

■ 따라다니는 동료
  "companion": { "actor": 2, "image": "$gaji", "flag": "gaji", "name": "가지" }
  flag가 켜진 뒤부터 따라다니고, 배를 타면 숨습니다. (2번 배우가 없으면 자동으로 만듦)

■ 목표 안내 (화면 왼쪽 위)
  단계 { "goal": "동래로 가서 안용복을 만나자" }   지우려면 { "goal": "" }

■ 조건에 따라 나타나는 이벤트
  조사 지점에 "visible": { "flag": "sealions" }  → 그 전에는 보이지 않고 지나갈 수 있음

■ 원경 그림 바꾸기
  단계 { "parallax": "!dk_view_clear" }
  방에 "parallax": [ { "if": { "flag": "p7" }, "name": "!dk_view_clear" }, { "name": "!dk_view_fog" } ]
  (다시 들어와도 조건에 맞는 그림이 나옵니다)

■ 타이틀 안내 문구 위치
  "titlePromptY": 0.62   (0 = 맨 위, 1 = 맨 아래)

■ 찾아갈 곳 표시 (v3.1)
  조사 지점에 "mark": "배 창고", "markIf": { "noFlag": "p5" }
  → 조건이 맞는 동안 그 위에 노란 화살표 이름표가 통통 튑니다.

■ 불꽃 효과 (v3.1)
  단계 { "effect": "firework", "target": "이벤트 이름" }

■ 전체 화면 (v3.1)
  플러그인 설정 "시작할 때 전체 화면"(타이틀을 누르면 자동), "전체 화면 버튼"(화면 위쪽 버튼)
  컴퓨터·안드로이드 브라우저에서 동작, 아이폰은 지원 안 함(버튼 자동 숨김), Windows 배포판은 F4.

F. 잠행 · 미션 · 타이밍 · 퀴즈 힌트 (v3.2) - 광주 편에서 처음 사용
=====================================================
■ 감시하는 사람 (잠행)
  방에 "watchers": [ { "event": "순사1", "route": [[10,6],[30,6]], "sight": 4, "speed": 3, "wait": 50 } ]
   - route: 차례로 걸어갈 칸 (빈 목록 [] 이면 제자리에서 "look" 방향으로 두리번: [2,4,8,6])
   - sight: 앞으로 보는 칸 수 (2칸부터 양옆 1칸씩 넓어짐, 벽 리전(1)에 막힘)
   - 화면에 빨간 칸으로 보이고, 들어가면 들킴 → "caught" 단계 → "checkpoint" 자리로
  "watchIf": 조건   감시가 켜지는 때 (예: 종을 친 뒤부터 {"flag":"bell"})
  "caughtPenalty": 30   들킬 때마다 30초 줄이기 (선택)
  ※ "visible" 조건으로 숨은 감시자는 보지 않음 (예: 동지가 따돌린 순사)

■ 미션 (제한 시간 안에 여러 사람에게 말 걸기)
  { "mission": { "targets": ["c1","c2"], "time": 80, "label": "쪽지 전하기", "doneText": "건넸다!",
                 "success": [...], "fail": [...] } }
   - 실패하거나 들키면 처음부터 다시 (다시 안 하려면 "retry": false)
   - 미션 중에도 감시자는 움직임

■ 따라오는 사람들
  조사 지점에 "followDelivered": true  → 미션에서 말을 건 뒤 주인공을 따라옴
             "follow": {"flag":"march"} → 조건이 맞으면 따라옴

■ 타이밍 미니게임 (등사기)
  { "timing": { "goal": 10, "per": 100, "unit": "장", "maxMiss": 3, "speed": 1.3, "zone": 0.24,
                "label": "등사기로 격문 찍기", "success": [...], "fail": [...] } }
   - 바늘이 초록 칸에 올 때 Enter·클릭·톡. 실수가 maxMiss를 넘으면 실패

■ 퀴즈 힌트
  데이터 "hintQuizzes": [ { "question": "...", "choice": ["가","나"], "answer": 1, "explain": "..." } ]
   - 힌트 3번을 다 쓴 뒤 H를 누르면 퀴즈 → 맞히면 힌트 1개 더

■ 사료 카드 수집
  데이터 "archives": ["arc1", ...]  (아이템 id) → 엔딩 기록에 "모은 사료: n / 8장"
  "recordTitle": "그날의 함성을 이었다!"  엔딩 기록 제목

■ 밤 화면 / 화면 색
  방에 "tint": [-68,-60,0,40]  (빨강, 초록, 파랑, 회색)   단계 { "tint": [...], "duration": 60 }

■ 글 속 바꿔 넣기
  데이터 "vars": {"동료":"은희"} → 글에 {동료} 라고 쓰면 바뀜 (주인공 고르기 "vars"로 바꿀 수도 있음)
  주인공 고르기 목록에 "flag", "companion": {"image": ...} 를 적으면 고른 주인공마다 다르게

■ 없는 그림 건너뛰기
  확대 그림·아이템 그림 파일이 없어도 멈추지 않고 빈 그림으로 넘어갑니다. (콘솔에 경고)

■ 인트로 영상 건너뛰기 (v3.2)
  기본: 영상은 건너뛸 수 없고 끝까지 재생됩니다. (영상 파일이 고장 나 멈추면 자동으로 넘어감)
  건너뛰게 하려면 데이터 맨 위에 "movieSkip": true  또는 단계 { "movie": "이름", "skip": true }

G. 체력 · 함정 · 활 · 어둠 (v3.4) / 조건 단계 · 겹치기 그림 (v3.5) - 중국사 편에서 처음 사용
=====================================================
■ 체력 하트
  데이터 맨 위 "hp": 3 → 오른쪽 위에 하트 3개.
  단계 { "damage": 1 } / { "heal": 1 } / { "fullHeal": true }
  하트가 다 떨어지면 방의 "ko": [단계...] 를 보여 주고 방의 "checkpoint" 자리에서 다시 시작.

■ 무작위 함정
  방 "traps": { "tiles": [[x,y], ...], "count": 5, "kind": "pit" }
   - tiles 후보 칸 중 count 개를 방에 들어올 때마다 무작위로 고름
   - "pit" 진흙 구덩이(밟으면 드러나고 하트 -1), "spike" 오르내리는 가시, "mixed" 섞기
  방 "trapsIf": 조건  → 그 조건일 때만 함정이 켜짐

■ 움직이는 것 (통나무, 수레, 박쥐, 말 …)
  방 "movers": [{ "event": "수레1", "route": [[0,17],[43,17]], "speed": 3, "damage": 1,
                  "loop": "restart", "wait": 60, "if": 조건 }]
   - 부딪히면 하트 -1. loop "restart"는 끝에 닿으면 처음 자리로 순간이동해 다시 출발.

■ 활
  방 "bow": true 또는 조건(예: { "item": "bow" })
   - 키보드 A·F: 바라보는 쪽으로 / 화면 오른쪽 아래 🏹 버튼 / 과녁을 손가락·마우스로 누르면 그쪽으로
  조사 지점에 "target": { "flag": "맞힘", "steps": [...] } → 화살로 맞히면 실행
  미션 중에는 화살로 맞힌 과녁이 미션 대상으로 셈 (활쏘기 시험)
  리전 4 = 낮은 울타리: 걸어서는 못 가지만 화살은 넘어감 (과녁 줄에 칠하기)

■ 어둠
  방 "dark": 3 → 주인공 둘레 3칸만 보임.  "darkArea": [x0,y0,x1,y1] → 그 구역 안에서만 어두움
  아이템 "effect": "light" 를 가지고 있으면 하나마다 +2칸

■ 숨은 아이템 효과
  아이템 "effect": "speed"(걸음이 빨라짐) / "charm"(감시에 한 번 들켜도 괜찮음, 쓰면 사라짐) / "light"

■ 무작위 문제
  단계 { "random": [[단계...], [단계...], [단계...]] } → 셋 중 하나를 무작위로 (갑골 점 문제 등)

■ 조건 단계 (v3.5)
  { "if": { "flag": "hall1" }, "then": [단계...], "else": [단계...] }

■ 겹치기 그림 (v3.5) - 연표 도전대
  { "picture": "cu_chronicle_board", "overlays": [ { "picture": "cu_slot_1", "if": { "flag": "slot1" } }, ... ] }
  같은 크기(640x360)의 투명 그림을 조건이 맞을 때만 위에 겹쳐서 보여 줍니다.

■ 방별 힌트 (v3.5)
  "puzzles" 항목에 "rooms": ["grotto"] → 그 방에 있을 때 그 힌트를 먼저 보여 줌

K. 시네마틱 · 초점 촬영 · 표정 초상화 (v4.0) - 「종로 사진관 1945–1953」에서 처음 사용
=====================================================
  ※ 이 묶음의 EscapeRoom.js는 v3.7(보내 주신 판)에 v4.0 기능을 더한 것입니다.
    중세 편(v3.8~3.9)의 기사 전투 기능은 들어 있지 않으니, 「시간의 서」 프로젝트에는 그 묶음의 EscapeRoom.js를 그대로 쓰세요.

■ 시네마틱 (검은 띠 + 장면 자막)
  { "cinema": true, "caption": "1945년 8월 15일 낮 12시 · 서울 종로" }  → 위아래 검은 띠 + 한 글자씩 나오는 자막
  { "cinema": false }  → 띠 걷기. 단계가 다 끝나 플레이어가 움직일 수 있게 되면 저절로 걷힘
  { "caption": "1946년 6월 · 종로 거리" }  → 시네마틱이 아닐 때는 화면 위쪽 반투명 띠에 자막
  시네마틱 중에는 위쪽 표시줄·목표·하트가 숨고, 경비병(잠행)도 멈춥니다.

■ 카메라 (확대 · 천천히 옮기기)
  { "zoom": { "event": "radio", "scale": 1.7, "duration": 70 } }   → 그 이벤트가 화면 가운데로 오며 확대
  { "zoom": { "x": 14, "y": 9, "scale": 1.4 } }                    → 칸 좌표로
  { "zoom": { "event": "flagpole", "dy": -2 } }                    → 조금 위쪽(dy칸)을 비춤
  다른 곳으로 다시 쓰면 그쪽으로 천천히 옮겨 갑니다(패닝).  { "zoom": false } → 원래대로

■ 인물 움직이기
  { "move": { "event": "patriot1", "to": [13, 5], "speed": 2 } }            → 그 칸까지 걸어감 (끝날 때까지 기다림)
  { "move": { "event": "us_del1", "route": [[12, 9], [12, 6]], "speed": 2, "wait": false } }   → 기다리지 않고 다음 단계로
  "erase": true → 도착하면 사라짐,  "dir": "left" → 도착 뒤 방향,  "through": false → 벽을 피해 길 찾기
  여러 명 동시에: { "move": [ {...}, {...} ] }   ("wait": false 인 것들 + 마지막 하나만 기다리기)
  "event": "player" 는 주인공
  { "place": { "event": "dad", "x": 17, "y": 4, "dir": "up" } }   → 순간 이동 (+ "opacity": 0 이면 투명)
  { "turn": { "event": "dad", "toward": "player" } } / { "turn": { "event": "kimgu", "dir": "left" } }
  { "balloon": { "event": "dad", "id": 1 } }   → 머리 위 말풍선 아이콘(! ? 등, MV 기본 그림)
  ※ 움직일 이벤트는 그때 보이는 상태여야 합니다("visible" 조건 확인).

■ 인물보다 위에 그리는 그림 (나무 윗부분·처마)

                         "commands": ["앞으로 가","두 걸음 앞으로","우향우","좌향좌","뒤로 돌아"], "max": 8, "solution": [2,1,0,3,1,1] }
- weigh  저울 두 번: { "type": "weigh", "count": 9, "uses": 2 }  무거운 자루는 플레이어가 운으로 맞힐 수 없게 저울 결과에 따라 정해짐
- beacon 봉수 올리기: { "type": "beacon", "count": 5, "rounds": [{ "text": "상황", "answer": 2, "why": "설명" }], "rules": [...] }

- 방 "push": 돌 밀기 { "stones": ["stone1",...], "targets": [[x,y],...], "when": {조건}, "flag": "끝 깃발", "done": [단계] }
             단계 { "pushReset": true } 로 돌을 처음 자리로 (막혔을 때 NPC에게 부탁하는 선택지로 쓰기 좋음)
- 방 "watchTurn": true + "watchers": 감시자가 주인공이 한 칸 움직일 때만 한 칸 움직임 (차례 잠행, 시야는 붉은 칸으로 보임)
- 퀘스트 게이지 "gauge": { "var": "tension", "label": "협상장 긴장", "min": 0, "max": 10 } → 단계 { "setVar": { "tension": "7" } }, 빈 값이면 숨김

■ v4.7 (「갑신년 그날 밤, 우정총국」)에서 더한 것
 · "game": { "type": "typeset", "rounds": [{ "text": "漢城旬報", "extra": ["新"], "note": "설명" }], "okLabel": "찍어 보기" }
     활자 조판: 판에는 거울처럼 뒤집힌 활자를 맨 오른쪽 글자부터 놓아야 종이에 바르게 찍혀요.
 · "game": { "type": "defend", "image": "지도", "gates": [{ "label": "돈화문", "x": 0.3, "y": 0.9 }], "units": [{ "label": "부대", "withdraw": true }],
             "track": 3, "waves": [[1, 2], ...], "withdrawAt": 5, "withdrawMsg": "…", "lose": 2, "heldVar": "held" }
     턴제 방어 (정해진 실패): 차례마다 waves 의 문에 깃발이 한 칸씩 다가옴. 부대가 있는 문은 막고, 없으면 뚫림.
     withdrawAt 차례에 withdraw 부대가 물러남. 뚫린 문이 lose 개가 되거나 waves 가 끝나면 언제나 success 로 이어짐. 버틴 차례 수는 변수 heldVar.
 · 데이터 맨 위 "clock": { "var": "clock" } → 변수 clock 에 글을 넣으면 화면 위 가운데 시계 띠가 보임 ({"setVar": {"clock": "12월 4일 · 밤 10시"}})
 · 퀘스트 표시 '!' 는 오브젝트 그림의 실제 꼭대기를 가리키고, 아직 안 본 물건 위에는 가까이 가면 흰 '?' 가 떠요.
   '?'를 띄우지 않을 조사 지점은 "noQ": true
 · fonts/EscHanja.ttf 가 있으면 한자를 그 글꼴로 그림 (tools_kr/k_data.py 가 데이터 속 한자만 골라 자동으로 만듦)
